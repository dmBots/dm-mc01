## 2. 旧例程默认界面核对

旧工程 `Core/Src/main.c` 的默认流程不是单独显示一张图片，而是：

1. 初始化 LCD 并清为黑色。
2. 在 `(120,72)` 显示棕红色 `dmBot`，12×24 ASCII 字体。
3. 在 `(84,100)` 显示白色 `达妙科技`，32×32 汉字字模。

当前例程已按上述布局恢复。旧代码把高度 240 的屏幕竖线画到 Y=280，本次将终点限制为 Y=239，避免越界。

## 3. LCD 硬件配置

| 屏幕信号 | 原理图网络/MCU 引脚 | 配置 | 作用 |
| --- | --- | --- | --- |
| CS | SPI1_CS / PA4 | GPIO 推挽输出，初始高 | 软件片选，低有效 |
| SCK | SPI1_SCK / PA5 | SPI1 AF5 | 串行时钟 |
| SDA | SPI1_MOSI / PA7 | SPI1 AF5 | 单向显示数据 |
| BLK | IIC2_SCL / PB3 | GPIO 推挽输出 | 背光，高有效 |
| RES | IIC2_SDA / PB4 | GPIO 推挽输出、上拉 | 硬件复位，低有效 |
| DC | PC01 / PC1 | GPIO 推挽输出 | 命令/数据选择 |

`IIC2_SCL` 和 `IIC2_SDA` 在 LCD 用途中只是原理图网络名，分别作为 BLK 和 RES 普通 GPIO 输出，不启用 I2C 功能。

SPI1 配置为主机、8 bit、MSB first、CPOL Low、CPHA 1 Edge（Mode 0）、内部 NSS、预分频 16。板端实测 SPI1 内核时钟 144 MHz，SCLK 为 9 MHz。SPI1 TX 使用 LPDMA2 Channel 3。

## 4. ADC2 五向按键配置

| 项目 | 配置 |
| --- | --- |
| 网络名 | ADC2_CH4_KEY |
| MCU 引脚 | PC4 / ADC2_IN4 |
| 分辨率 | 12 bit |
| 采样时间 | 289 cycles |
| 转换方式 | 软件触发、单次规则组转换 |
| DMA | LPDMA2 Channel 2，外设到内存，word 宽度 |
| 采样周期 | 20 ms |
| LCD 刷新周期 | 100 ms |
| 单次采样超时 | 10 ms |

旧例程只显示 ADC 原始值，没有给出上、下、左、右、中心五个档位的电压阈值。本次保持这一行为，不对阈值作未经实测的假设；BSP 和应用 API 已提供 12 位原始值及序号，后续可采集五个按键档位后增加方向解析。

## 5. 软件结构

- `board/board_config.h`：LCD 与按键 ADC 的周期、超时、尺寸及引脚配置。
- `board/bsp/bsp_lcd.c/.h`：轻量 LCD 总线接口，负责 GPIO、SPI1 DMA 和中断事件。
- `board/bsp/bsp_adc.c/.h`：ADC1 VBAT 与 ADC2 KEY 共用的轻量异步 DMA 采样实现。
- `app/key_test.c/.h`：按键连续采样、状态统计及最新原始值用户接口。
- `app/lcd.c/.h`：ST7789 非阻塞初始化、区域填充和 RGB565 图片发送。
- `app/lcd_font.c/.h`：只迁移默认界面使用的 ASCII 24、ASCII 32 和四个中文 32 字模。
- `app/lcd_picture.c/.h`：旧工程 RGB565 图片资源。
- `app/lcd_test.c/.h`：旧默认界面绘制、初始计数自检和按键值持续刷新状态机。

ADC 与 SPI 中断回调只设置完成/错误标志。停止 DMA、发布采样、界面步骤推进和刷新均在主循环轮询中处理。
