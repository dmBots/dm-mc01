# MC01-RC IMU 加热温控实板测试报告

## 1. 测试结论

测试日期：2026-09-08

基于 BMI088 内部温度数据和 TIM2_CH3/PB10 的 1 kHz PWM，IMU 加热闭环温控功能通过实板测试。温度从 30.50°C 上升并稳定在 45°C 附近，记录到的最高温度为 46.25°C，最大过冲为 1.25°C。温控长期运行测试的最终观测温度为 45.000°C，占空比为 15.6%，已连续约 107 秒保持在目标温度 ±0.5°C 范围内，控制器和传感器故障码均为 0。

六轴采集门控也通过实板测试：升温阶段仅以 1 kHz 读取温度；温度连续 10 秒处于 45°C ±0.5°C 后，自动启用加速度计和陀螺仪 1 kHz 采集。门控前六轴样本数保持为 0，门控后读取错误和漏采均为 0。

## 2. 测试环境

- 目标器件：STM32C5A3RGT6
- 温度反馈：BMI088 内部温度数据
- PWM 输出：TIM2_CH3 / PB10
- PWM 配置：1 kHz、PWM1、高有效、初始占空比 0%
- 加热电源使能：PC15，高有效
- 板卡供电：24 V 已接入
- 调试器：DAPLink，UID `D641959C00B43ECC`
- 下载与调试工具：项目 `.venv` 中的 pyOCD
- 构建预设：`debug_GCC_STM32C5A3RGT6`

pyOCD 下载时提示目标包缺少 Flash programming debug sequence，随后自动回退到 FLM；擦除和编程均成功，不影响测试结论。

## 4. 软件结构

- `board/bsp/bsp_heater.c`：仅封装 TIM2_CH3 启动、千分比占空比设置和安全关闭。
- `app/imu_heater.c`：实现整数 PI、积分抗饱和、温度稳定判定、传感器超时和过温保护。
- `app/imu_test.c`：升温阶段以 1 kHz 读取 BMI088 温度，稳定满 10 秒后再启用加速度计和陀螺仪 1 kHz 采集。
- `main.c`：在现有协作式主循环中依次轮询 IMU 采样和温控应用，不使用阻塞延时。

温控初始化时先关闭加热 5 V，确保 PWM 以 0% 启动后再打开电源。传感器失效、PWM 设置失败或温度达到 60°C 时，会将 PWM 置零、停止 TIM2 通道并关闭加热 5 V 使能。

## 5. 测试方法

1. 使用 CMake Debug 预设编译固件。
2. 使用 DAPLink + pyOCD 下载 ELF 并复位运行。
3. 分阶段暂停 MCU，读取 `imu_heater_status`、`imu_test_status`、TIM2 寄存器和 GPIOC 输出寄存器。
4. 核对升温过程中的温度、误差、占空比、稳态时间、峰值温度和故障状态。
5. 在达到目标后继续运行约 3.5 分钟，检查积分回退和长期稳态。
6. 重新下载采集门控固件，分别在升温阶段、接近目标温度以及稳定满 10 秒后读取温度与六轴计数器。

## 9. 结论边界

本次实测证明 1 kHz PWM 输出、BMI088 温度反馈、PI 调节、占空比限幅、稳态控制和稳温后六轴采集门控有效。由于缺少加热小板原理图，当前 50% 最大占空比作为保守限制保留；若更换加热小板、电阻阻值、MOSFET 或机械安装方式，需要重新验证升温速度并调整 PI 参数。

过温和传感器超时关闭路径已进行源码与构建检查。本次没有人为将板卡加热到 60°C 来触发过温保护，以避免不必要的硬件热应力。
