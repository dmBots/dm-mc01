# MC01-RC 无源蜂鸣器实板测试报告

## 1. 测试结论

测试日期：2026-09-07

TIM3_CH3 蜂鸣器控制与非阻塞旋律测试通过。测试固件能够按照音符表动态改变 PWM 频率，正确执行中间休止，并在整段旋律播放完成后自动停止 TIM3 和 CH3 输出。

此前版本已由用户现场耳听确认蜂鸣器能够正常发声。本次 Spidey Tracker 开场音版本已完成编译、下载和寄存器级验证，旋律相似度与最终听感以用户现场试听为准。

## 2. 测试环境

- 目标器件：STM32C5A3RGT6
- PWM 输出：PB0 / TIM3_CH3
- TIM3 时钟：144 MHz
- TIM3 预分频：143，计数频率 1 MHz
- PWM 模式：向上计数、PWM Mode 1、约 50% 占空比
- ARR preload：开启
- CCR3 preload：开启
- 调试器：DAPLink，UID `D641959C00B43ECC`
- 下载与调试工具：项目 `.venv` 中的 pyOCD
- 构建预设：`debug_GCC_STM32C5A3RGT6`

## 3. 软件结构

- `board/bsp/bsp_beep.c`：轻量封装初始化、频率设置、启动和停止 API。
- `app/beep_music_test.c`：保存 Spidey Tracker 开场音的单声部近似旋律，并通过 `HAL_GetTick()` 推进非阻塞播放状态机。
- `main.c`：在主循环中轮询 `beep_music_test_process()`，播放过程不使用阻塞延时。
- `board/board_config.h`：集中保存 TIM3 时钟、默认 4 kHz 频率和占空比配置。

参考音源为 [Spidey Tracker](https://spideytracker.net/) 页面使用的约 2.09 s 开场音效。分析得到的主旋律为 `C#5-E5-G#5`、约 0.45 s 休止、`G5-E5-C#5`。考虑到蜂鸣器的标称谐振频率为 4 kHz，保持音程关系并移调为 `G#7-B7-D#8`、休止、`D8-B7-G#7`，PWM 频率范围为 3322 Hz 至 4978 Hz。原始 MP3 未加入工程或固件。

## 4. 验证方法

1. 使用 CMake Debug 预设构建 ELF。
2. 使用 DAPLink + pyOCD 下载并复位运行。
3. 在旋律播放的不同时刻暂停 MCU，读取播放状态以及 TIM3 的 CR1、CCER、PSC、ARR 和 CCR3。
4. 在旋律结束后再次读取状态和 TIM3 使能位，确认输出已停止。

## 6. 结论边界

本次通过调试器确认了软件状态机、动态频率、休止处理、PWM 占空比和启停控制。蜂鸣器只能输出单频方波，无法复现网页音效中的音色、混响及多声部；实际响度和旋律听感需要现场耳听确认。如听感偏尖或个别音符偏弱，只需在应用层调整移调范围和音符时值，不需要修改 BSP。
