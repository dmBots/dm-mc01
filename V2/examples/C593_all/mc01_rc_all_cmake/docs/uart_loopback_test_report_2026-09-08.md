# USART1 / USART3 DMA 自回环测试报告

## 1. 测试结论

测试通过。

USART1 和 USART3 均按“单个串口自回环”连接并独立测试，不是 USART1 与 USART3 互联。两路串口分别完成 17、64、128 字节的 DMA 发送、DMA 接收、软件队列入队及逐字节数据校验，共 6 个用例全部通过。

## 2. 测试环境

- 目标芯片：STM32C5A3RGT6
- 调试器：DAPLink
- 下载及调试工具：pyOCD
- 固件：`build/debug_GCC_STM32C5A3RGT6/mc01_rc_all.elf`
- 测试日期：2026-09-08
- 串口配置：115200 baud，8 数据位，无校验，1 停止位
- RX DMA 缓冲区：128 字节，循环链表模式
- RX 软件队列：512 字节
- 接收超时：150 bit times

## 3. 硬件连接

| 测试端口 | TX | RX | 连接方式 |
| --- | --- | --- | --- |
| USART1 / P10 | PA9 | PA10 | PA9 与 PA10 互联，USART1 自回环 |
| USART3 / P13 | PC10 | PC11 | PC10 与 PC11 互联，USART3 自回环 |

两个串口之间没有交叉连接，也没有进行 USART1 到 USART3 的互发测试。

## 4. 软件实现

### 4.1 BSP

`board/bsp/bsp_uart.c` 保留轻量用户接口：

- 配置波特率、接收超时并启动循环 RX DMA；
- 使用 TX DMA 异步发送；
- 提供软件接收队列的读取和待接收字节数查询；
- 提供错误、丢包以及 DMA 半满、全满、接收超时事件计数。

RX 数据只在中断回调中按 DMA 当前位置增量搬入软件队列：

- DMA 半满回调：提交前半段新增数据；
- DMA 全满回调：提交后半段新增数据并处理循环回卷；
- UART 接收超时回调：提交不足半缓冲区的不定长尾部数据。

RS485 与普通 UART 共用一套 HAL 全局 UART 回调入口，再按 UART 句柄分发，避免重复回调符号。

### 4.2 APP

`app/uart_loopback_test.c` 使用主循环轮询状态机推进测试，不阻塞 CAN、RS485、USB、LED 等任务。

每个端口的覆盖长度为：

- 17 字节：验证接收超时提交不定长数据；
- 64 字节：覆盖 128 字节 DMA 缓冲区的半满路径；
- 128 字节：覆盖 DMA 全满和循环回卷路径。

## 6. 回归结果

由于本次增加了 UART 句柄分发，对已有 UART 类外设同时进行了板上回归：

- RS485 2 Mbaud 外部 Echo：通过掩码 `0x3F`，错误及丢包均为 0；
- CAN 当前 FD8M 预设：通过掩码 `0x0F`，CAN1/CAN2 内部回环和双向外部回环均通过，错误计数为 0。

## 7. 最终判定

USART1 和 USART3 的轻量用户 API、循环 DMA 不定长接收队列和独立外部自回环例程满足本次需求，板上测试及相关回归测试均通过。
