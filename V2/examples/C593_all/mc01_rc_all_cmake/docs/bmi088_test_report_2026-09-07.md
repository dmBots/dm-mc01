# MC01-RC BMI088 实板测试报告

## 1. 测试结论

测试日期：2026-09-07

BMI088 的 Bosch SensorAPI 移植、SPI2 轻量 BSP、1 kHz 轮询采集例程均通过实板测试。加速度计、陀螺仪和温度数据能够持续更新；持续观测到 75952 组样本时，SPI/API 读取错误为 0，轮询漏采计数为 0，记录到的轮询间隔最小值和最大值均为 1 ms。

## 2. 测试环境

- 目标器件：STM32C5A3RGT6
- 传感器：BMI088
- 板卡供电：24 V 已接入
- 调试器：DAPLink，UID `D641959C00B43ECC`
- 下载与调试工具：项目 `.venv` 中的 pyOCD
- 构建预设：`debug_GCC_STM32C5A3RGT6`
- SensorAPI：Bosch BMI08x SensorAPI 1.9.0，放置于 `middleware/bmi08x`

pyOCD 下载时提示目标包缺少 Flash programming debug sequence，随后自动回退到 FLM；固件擦除、编程、复位和调试读取均成功，该提示不影响本次测试结论。

## 3. 硬件与参数配置

| 项目 | 配置 |
| --- | --- |
| SPI 外设 | SPI2，主机，全双工，8 bit，约 9 MHz，Mode 3 |
| SCK | PB2 |
| MISO | PB14 |
| MOSI | PB15 |
| 加速度计片选 | CS0 / PB1，软件控制，低有效 |
| 陀螺仪片选 | CS1 / PC5，软件控制，低有效 |
| 加速度计量程 | ±24 g，BMI088 最大量程 |
| 加速度计 ODR | 1600 Hz，最高 ODR，Normal 带宽 |
| 陀螺仪量程 | ±2000 °/s，最大量程 |
| 陀螺仪 ODR | 2000 Hz，230 Hz 带宽，最高 ODR |
| 应用轮询周期 | 1 ms，即 1 kHz |
| SensorAPI 配置块长度 | 32 byte |

片选对应关系按硬件定义固定为 `CS0=加速度计`、`CS1=陀螺仪`，未实现自动交换探测。

## 4. 软件结构

- `middleware/bmi08x`：保存 Bosch 原版 SensorAPI 源码、头文件和许可证。
- `board/bsp/bsp_spi2.c`：仅封装 SPI2 Mode 3 初始化、软件片选、全双工传输和微秒延时，未放入 BMI088 配置或测试状态机。
- `app/imu_test.c`：实现 Bosch 接口适配、传感器复位与初始化、量程/ODR 配置、1 kHz 非阻塞轮询、单位换算和测试状态记录。
- `board/board_config.h`：集中保存 SPI2 片选、超时、BMI088 片选映射、轮询周期和测试样本数等宏定义。
- `main.c`：在现有轮询式多任务主循环中调用 `imu_test_process()`。

初始化时先识别两颗芯片，再分别执行软复位和重新初始化，随后加载加速度计配置文件并设置工作模式。该处理可消除 MCU 启动阶段片选初始电平对加速度计启动状态的影响。

## 5. 测试方法

1. 使用 CMake Debug 预设构建 ELF。
2. 使用 DAPLink + pyOCD 下载 ELF，复位并运行目标板。
3. 通过调试器读取 `imu_test_status`，核对芯片 ID、配置读回、电源寄存器、样本数、数据就绪次数、错误和漏采计数。
4. 在约 2 秒、约 5 秒和持续运行约 76 秒时分别暂停 MCU 读取状态，随后恢复运行。
5. 检查加速度、角速度和温度数据是否有效且持续变化。

## 6. 构建与配置读回

- 构建结果：成功，无编译或链接错误。
- 固件尺寸：text 91664 byte，data 248 byte，bss 15488 byte。
- 加速度计 Chip ID：`0x1E`，符合 BMI088。
- 陀螺仪 Chip ID：`0x0F`，符合 BMI088。
- 加速度计 ODR/量程读回：`0x0C` / `0x03`，对应 1600 Hz / ±24 g。
- 陀螺仪 ODR/量程读回：`0x01` / `0x00`，对应 2000 Hz、230 Hz 带宽 / ±2000 °/s。
- 加速度计 `PWR_CONF`：`0x00`。
- 加速度计 `PWR_CTRL`：`0x04`。
- 加速度计 `INTERNAL_STAT`：`0x01`，配置文件初始化成功。

| 观测点 | 样本数 | 数据就绪数 | 读取错误 | 漏采 | 最小/最大间隔 | 结果 |
| --- | ---: | ---: | ---: | ---: | --- | --- |
| 约 2 s | 1827 | 1827 | 0 | 0 | 1 ms / 1 ms | 通过 |
| 约 5 s | 4849 | 约 4850 | 0 | 0 | 1 ms / 1 ms | 通过 |
| 持续运行约 76 s | 75952 | 75952 | 0 | 0 | 1 ms / 1 ms | 通过 |

约 5 秒快照在应用更新数据就绪计数与样本计数之间暂停，因此两者相差 1；后续完整快照中两者一致。

| 观测点 | 加速度原始值 X/Y/Z | 加速度 X/Y/Z | 陀螺仪原始值 X/Y/Z | 角速度 X/Y/Z | 温度 |
| --- | --- | --- | --- | --- | ---: |
| 约 2 s | 59 / 76 / 1366 | 43 / 55 / 1000 mg | -8 / 13 / 4 | -488 / 793 / 244 mdps | 29.625 °C |
| 约 5 s | 60 / 66 / 1350 | 43 / 48 / 988 mg | -8 / 1 / 2 | -488 / 61 / 122 mdps | 29.500 °C |

## 8. 问题定位记录

初版在不执行显式软复位时，两颗芯片 ID、加速度计配置文件状态和电源寄存器均能正确读回，但加速度计数据就绪始终为 0，采样值全零。将 SPI2 按 Bosch 参考配置为 Mode 3，并在正式配置前对加速度计和陀螺仪执行 SensorAPI 软复位与重新初始化后，加速度计数据就绪和六轴采样恢复正常。最终测试使用该确定性初始化流程。

## 9. 结论边界

本次验证覆盖 SensorAPI 集成、SPI2 通信、软件片选、芯片识别、配置加载、最高量程/ODR 设置、六轴与温度采集、1 kHz 协作式轮询及约 76 秒持续运行。轮询周期由 1 ms 系统节拍驱动，报告中的 1 ms 间隔是毫秒级调度统计，不代表微秒级抖动测量；由于传感器 ODR 高于应用轮询频率，应用不会读取每一个传感器转换样本。
